# Homebrew tap for SwiftNote

[SwiftNote](https://github.com/TheShadowNinjaGMD/SwiftNote) is a quick-note app that lives in your Mac's menu bar.

```sh
brew tap TheShadowNinjaGMD/swiftnote
brew install --cask swiftnote
```

Or in one line, without tapping first:

```sh
brew install --cask TheShadowNinjaGMD/swiftnote/swiftnote
```

Update with `brew upgrade --cask swiftnote` (SwiftNote also updates itself). Remove with `brew uninstall --cask swiftnote`.
Your notes are never deleted by uninstalling.
